# Atelier Préparation de Données Textuelles

Pipeline de préparation de données textuelles (avis clients) pour une classification de sentiment : exploration, nettoyage, tokenisation, normalisation, vectorisation.

## Installation
\`\`\`bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
\`\`\`

## Structure
- `notebooks/atelier_prepa_donnees_textuelles.ipynb` — notebook principal
- `data/` — données brutes et transformées
